pdffigures2.jar must be copied here from the project root.

To copy the JAR file, run the following command from the project root (d:\reportgps):

    copy pdffigures2.jar services\figure-analyser\pdffigures2.jar

Or in PowerShell:

    Copy-Item pdffigures2.jar -Destination services\figure-analyser\pdffigures2.jar

The figure-analyser service will NOT function without pdffigures2.jar present in this directory.
The /health endpoint will report jar_found: false if the JAR is missing.
